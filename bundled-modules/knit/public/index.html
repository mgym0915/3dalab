FROM SCREEN TO OBJECT

从织形，到实物。

  1. 本地运行

    Windows 本地包解压后双击 Start-Knitform.cmd。浏览器打开本机地址，计算、图案和 G-code 均留在本机；无需登录或联网。用 Stop-Knitform.cmd 关闭服务。也可直接打开离线 HTML。

  2. 自定义图案

    打开“图案与路径工作台 → 图案编辑器”。可用画笔、填充、矩形、擦除，或导入图片、输入文字。横向是器物圆周，底部是先打印的层；A–D 分别对应 T0–T3。选择每图案行跨几层、旋转角度和圆周重复次数，点击“应用图案并计算路径”。

  3. 让同色逐层对齐

    例如 AB 序列、每行 6 层：这一行有 3 层 A 和 3 层 B。图案需要 A 的位置，A 层向外、B 层向内；需要 B 的位置则相反。同色路径使用固定针相位，图案锁在同一个角度，不随奇偶层半针位移漂移。外凸与内收深度可调，边缘平滑过渡。

  4. 准备实际拓竹切片

    选择当前造型，或导入原始模型/单色已切片 3MF。在工作台选择实际打印机与耗材，勾选自动换色，点击“一键生成拓竹打印文件”。软件调用本机 Bambu Studio 和官方机型配置，自动生成启停、温度、AMS、冲刷、擦料塔及逐层色槽；无需去拓竹界面补颜色。

  5. 导入、检查、导出

    自动出片会补齐图案所需色槽；新增 C/D 会加入逐层序列。软件逐层核对实际颜色，计算提花并重算挤出，检查平台、流量与搭接。仅有 G-code 的切片包会按原墙路径恢复同心空心器物，恢复来源显示在报告中。查看中心线、实体线宽和相邻两层，再下载 .gcode.3mf 或 G-code。用 Bambu 查看器核对，勿再次切片。

  6. 保存可编辑工程

    主界面“保存工程”保存造型、配色、针法和已应用图案。图案也可单独导出 .knitpattern 或 PNG。自动存档保存在当前浏览器，不同浏览器或端口互不共享；使用工程文件迁移。导入的原始切片不嵌入工程，重新打开时需再次选择原文件。

预览与实物的边界

提花依靠同色路径的外凸和内收，不是把每条线直接换成目标颜色。内收颜色仍可能露出；实体预览按椭圆挤出截面近似，实际效果需要小样校准。接缝附近保留渐变区，图案顶端可能受层数裁切。自动出片的启停、AMS 和底板由所选机型的拓竹引擎生成；修改后原耗材、时间和缩略图不再代表最终路径。内置演示没有机器指令，不能作为打印文件导出。

建议先打印小样；灯罩配低温 LED，盛水花瓶可加内胆。当前尚未完成实机打印验证。
