# 标识字核算王 1.4.0

预计价格替代预计克重。主机一次计算光面4层/钻闪7层、打印单色/多色、灯光常亮/RGB共8组成本报价。贴墙安装仅作选择，不收费。不含管理费和利润。
字体轮廓偏移固定0，无界面编辑入口，API拒绝非零偏移。保留等比开关与独立宽高。
浏览器仅生成即时文字轮廓预览、展示主机报价；无浏览器重量或价格估算内核。尺寸、克重和辅料正式计费由Node worker计算，原yd身份及任务隔离不变。
连续点击在线核算7次后可点击价格查看全部材料用量与金额；手机离屏核算状态引导与价格状态同步。
灯带与超过780mm的辅料是经用户允许的几何估算，详见价格核算规则.txt。价格规则来自用户Excel与确认修正。
本轮仅执行价格、输入和受影响界面的有限检查。正式发布执行加载器必需的文件和包哈希，不运行全量测试。
