# 猫猫牌 3D 3.2.0

双击「启动猫猫牌3D.cmd」，浏览器打开 http://127.0.0.1:8742/。关闭服务使用「停止猫猫牌3D.cmd」。已包含 Node.js，无需安装依赖。

## 2–5 人联机

所有设备连接同一局域网。其他设备访问主机的局域网 IP 与 8742 端口，例如 http://192.168.31.177:8742/。主机的实际地址会打印在 runtime/server.log。

一人创建房间，其他人输入六位房间码加入。2–5 人到齐后，房主开始。每个人手选两张初始牌，记住后盖牌；所有人盖牌后开始行动。

房间满五人或开局后不能加入。刷新页面会恢复当前座位；退出会结束房间。房间保存在服务进程中，停止服务会结束正在进行的牌局。

「人机练习」由同一服务器裁定，AI 无法读取暗牌。右上角 1× / 2× 调整本机动画速度，不改变其他玩家的动画速度或记牌时间。

## 本版规则

- 52 张牌：0、13 各两张，1–12 各四张。
- 私下看过的牌盖回；全桌公开过的牌持续明牌，包括弃牌堆拿回的牌和一换多失败时亮出的原手牌。
- 私密抽牌立在空中，只有摸牌者可见；弃牌平放桌面、全桌可见。从弃牌堆拿回的牌继续公开。
- 成功换走无人看过的牌触发「赌」，奖励倍率 +10%；成功一换二触发「对子」再 +10%；成功一换三再 +30%。同一次可叠加。
- 恰好持有 12、12、13、13，立刻按所有人的实际手牌和结算小回合，触发者的奖励倍率 ×2。
- 0 可选择顺时针或逆时针传递整手牌。
- 每个人行动至少五次后，可在摸牌前喊 CATWIN，其他玩家各再行动一次。成功者局内记 0 分，失败者手牌和额外 +10；其余玩家按手牌和计分。
- 局内累计恰好 100 分降至 50；有人超过 100，整场结束，局内累计最少者获胜。

## 两种积分

局内分数用于判断整场胜负，越少越好。

3DAlab 通用积分：成功 CATWIN 奖励 10 × 个人倍率；整场胜利奖励 100 × 个人倍率。奖励从其他玩家平均扣除；整数余数按座位顺序分摊，各人最多差 1 分。并列整场赢家各获得对应奖励，由非赢家分摊。

个人倍率 = (1 + 赌次数 × 10% + 对子次数 × 10% + 三张次数 × 30%) × 2^1213次数。同一整场跨小回合累计，新整场重置。

独立运行显示本地积分计算，不会写入 3DAlab 账号。导入配套模块后，通过 3DAlab 的账号和积分服务入账；服务暂时不可用时持久保存待入账记录，重试不重复记分。AI 不作为真实账号参与榜单。

卡面和牌背来自用户提供的《猫猫牌卡面资料.zip》。使用对应的 0–13 卡面及猫咪图案牌背，未用资料包内旧规则图覆盖本版规则。

三维渲染需支持 WebGL 2。引擎和素材均在本地，无 CDN 依赖。
